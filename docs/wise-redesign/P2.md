# P2 项目概览 · Wise 重设计规格

> 画板 1920×1080。规范唯一真相源：`wise/DESIGN.md`。字体全局约定：显示层大标题 Noto Sans SC 900；次级标题/导航/Tab/按钮 Noto Sans SC 600；正文 Noto Sans SC 400。信息架构、功能区、文案全部保持现状，只换视觉。
> 本页核心换血：**清除现状蓝色第二强调色**（已确认数字、进度条、链接、头像），绿色只留给 CTA 与品牌强调（Tab 激活指示条），状态语义全部落到 positive/warning/negative 族。

## 2 全局元素规格

### TopBar（`{components.nav-bar}`）
- 背景 `{colors.canvas}` #ffffff，全宽 1920×64，无阴影无下边框。
- 左侧（x=48 起，水平居中排布，间距 24px）：
  - 品牌标：锚形图标 24×24 `{colors.ink}` #0e0f0c + 字标 "ShipMate" 20px · Noto Sans SC 900 · `{colors.ink}` #0e0f0c。
  - 面包屑：14px。"Maxon 实验室" 400 `{colors.mute}` #868685 → 分隔符 "/" 400 `{colors.mute}` #868685 → "ShipMate" 600 `{colors.body}` #454745（当前页加重一档，不用纯黑避免与字标争层级）。
- 右侧（右缘距 1872 对齐内容区）：用户头像 40×40 圆形 `{rounded.full}`，底 `{colors.ink}` #0e0f0c，字 "明" 14px · 600 · `{colors.canvas-soft}` #e8ebe6（替换现状蓝色头像；ink 反白属规范 card-feature-dark 的明暗翻转用法，不引入新色）。

### 项目上下文条（项目名 + Tabs，代替侧栏）
- 项目名 "ShipMate"：40px · Noto Sans SC 900 · `{colors.ink}` #0e0f0c（对应规范 `{typography.display-md}` 字号/字重；行高按中文放大为 48px）。右随 12px 处放 active 徽章（见第 5 节）。
- 描述行：上距 8px，16px · 400 · `{colors.body}` #454745。
- 右上角 agent 提示（与项目名同行、右对齐）：闪电图标 16px `{colors.mute}` #868685 + "agent 可经 MCP 读写此项目" 12px `{typography.caption}` `{colors.mute}` #868685。
- Tab 行：五 Tab 左对齐、间距 32px（`{spacing.2xl}`），行高 48px，无通栏分隔线（少边框红线）。
  - 激活 Tab「概览」：16px · Noto Sans SC 600 · `{colors.ink}` #0e0f0c；文字底部 0px 处一条 3px 高、与文字等宽、圆角 pill 的指示条 `{colors.primary}` #9fe870（品牌强调用途，依据规范 `ex-app-shell-row` 的 `activeIndicator: {colors.primary}`）。
  - 非激活 Tab：16px · Noto Sans SC 600 · `{colors.body}` #454745；hover 变 `{colors.ink}` #0e0f0c，无底色变化。
  - 不用蓝色、不做黑色粗下划线（现状样式弃用）。

## 3 逐区域详细规格

### 3.1 指标卡行（5 张，352×128）
- 结构：5 列网格，列距 16px。每卡：白底卡片（`{components.card-content}`），内部纵向排布：数字 → 8px → 标签。
- 卡片：背景 `{colors.canvas}` #ffffff，圆角 `{rounded.xl}` 24px，内距 24px，无边框无阴影（Level 0，靠鼠尾草底对比浮起）。
- 数字：32px · Noto Sans SC 900 · 默认 `{colors.ink}` #0e0f0c，行高 40px。
- 标签：14px · 400 · `{colors.body}` #454745，行高 20px。
- 五卡内容与数字用色（数字色仅语义卡偏离 ink，见第 5 节）：
  1. 「4 / 需求」— 数字 ink
  2. 「37 / 需求点」— 数字 ink
  3. 「18/37 / 已确认」— 数字 `{colors.positive-deep}` #054d28（正向语义，替换现状蓝）
  4. 「1 / 待重估」— 数字 `{colors.warning-deep}` #b86700（warning 族深文字，替换现状黄）
  5. 「1 / 已超期需求」— 数字 `{colors.negative}` #d03238（negative 族）
- hover：不变色不加阴影，整卡保持平贴（可选：指针手型，行为维持现状跳转，不做视觉承诺）。

### 3.2 模块进度区头（1824×40）

### 3.3 模块进度卡组（3 张，597×168）
- 结构：3 列网格，列距 16px。每卡纵向三行。
- 卡片：背景 `{colors.canvas}` #ffffff，圆角 24px，内距 24px，无边框无阴影。

### 3.4 最近动态卡（1824×320）
- 卡片：背景 `{colors.canvas}` #ffffff，圆角 24px，内距 24px。

- 每行结构（水平排布，垂直居中）：

## 6 与现状差异要点

1. **蓝色第二强调色全灭**：现状"18/37 已确认"蓝数字、蓝色进度条、蓝色"查看需求"链接、蓝色头像、蓝色"明"头像底全部清除——数字改语义族（positive-deep/warning-deep/negative），进度条改 positive #2ead4b，链接改 ink 加下划线，头像改 ink 反白。
2. **表面体系翻转**：页面底由白灰改为鼠尾草 `{colors.canvas-soft}` #e8ebe6，所有卡片纯白 24px 大圆角、无边框无阴影，层次完全靠表面对比；动态列表由"浅灰行条"改为白卡内 1px canvas-soft 细分隔线。
3. **显示层加重**：项目名与指标数字改 Noto Sans SC 900（40px / 32px），字标 900；Tab/按钮/卡标题统一 600；激活 Tab 由黑色下划线改为品牌绿 3px 圆角指示条。
4. **CTA 收敛为唯一绿点**：「新建模块」由描边小按钮升级为全页唯一 `button-primary` 亮绿 #9fe870 药丸（48px 高、24px 圆角、黑字）。
5. **徽章全面 pill 化并按语义族映射**：active=badge-positive（浅绿底深绿字，非品牌绿）、待重估=warning 黄族、超期=negative 深栗底白字、动态类型四分色（中性灰 / 浅绿 confirm / 中性绿 create），AI actor 用 ink 反白徽章与 human 区分。
