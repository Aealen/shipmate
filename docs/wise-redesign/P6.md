# P6 审计报表 · Wise 重设计规格

> 依据 `wise/DESIGN.md`（唯一真相源）。信息架构、功能区、文案全部保持现状（`.pen-export/wise-input/R3lvQY.png`），只换视觉设计语言。
> 中文字体全局约定：显示层大标题 "Noto Sans SC" 900；次级标题/导航/Tab/按钮/徽章 600；正文 400。

## 1 布局骨架

画板 1920×1080，页面整体底色 `canvas-soft` #e8ebe6（鼠尾草），内容纵向排布、超出视口自然滚动。

```
y 0–64      TopBar（白带 canvas #ffffff）
y 64–160    项目上下文条（白带，含项目名行 64–112 与 Tab 行 112–160）
y 160–184   无缝过渡：白带结束，进入鼠尾草内容画布
y 184–288   ① 审计统计卡行（4 卡等宽，高 104，间距 16）
y 304–536   ② 分布区行：左「操作者分布」卡（自适应宽 ≈1392）+ 右「变更实体类型分布」卡（固定宽 464），高 232，间距 16
y 536–572   间距 32（含 pills 上方呼吸）
y 572–608   ③ 过滤器 pills 行（高 36）
y 640–672   ④ 「变更时间线」区块标题行（高 32，与 pills 间距 32）
y 672 起    ④ 变更时间线列表（按 今天/昨天/更早 分组，事件行高 56、间距 8，组标题高 24、组间距 16）
```

- 内容区左右边距统一 24px（`spacing.xl`）。
- 白带（TopBar + 项目上下文条）与鼠尾草画布之间不画分隔线——靠表面对比分层（规范 Elevation Level 2）。
- 首屏 1080 内可见到：统计行、分布行、pills、时间线标题、今天组 3 行 + 昨天组标题；其余滚动。

## 2 全局元素规格

### TopBar（对应规范 `nav-bar`）
- 背景 `canvas` #ffffff，无描边无阴影，高 64px，水平内距 24px，内容垂直居中。
- 左组（从左到右，间距 12px）：
  - 品牌标识：锚形图标 20×20 `ink` #0e0f0c + 文字 "ShipMate"，"Noto Sans SC" 600 / 16px / #0e0f0c。
  - 面包屑："Maxon 实验室 / ShipMate / 审计"，"Noto Sans SC" 400 / 14px；前两级 `body` #454745，分隔符 "/" 用 `mute` #868685，当前级「审计」600 / 14px / `ink` #0e0f0c。
- 右组：用户头像，直径 36px 圆形（`rounded.full`），填充 `primary` #9fe870，文字「朗」"Noto Sans SC" 600 / 14px / `on-primary` #0e0f0c（品牌强调用法，非状态色）。

### 项目上下文条（白带下半部）
- 背景与 TopBar 连成一体：`canvas` #ffffff。
- **项目名行**（y 64–112，水平内距 24px）：
  - 左：项目名 "ShipMate"，"Noto Sans SC" 900 / 32px / `ink` #0e0f0c（本页显示层大标题），右侧间距 12px 放项目状态徽章。
  - 状态徽章 `badge-positive`：「active」，背景 `primary-pale` #e2f6d5，文字 `positive-deep` #054d28，"Noto Sans SC" 600 / 12px，圆角 pill，内距 4px 12px（`spacing.xs` `spacing.md`）。
  - 右：「项目概览 ›」文字链接，"Noto Sans SC" 600 / 14px / `ink` #0e0f0c，箭头 `mute` #868685；hover 加下划线。不用绿色文字（绿不作文字色，对比不足）。
- **Tab 行**（y 112–160，水平内距 24px，Tab 间距 8px）：
  - Tab 项：概览 / 需求分析 / 进度 / 任务看板 / 审计，内距 12px 16px，文字 "Noto Sans SC" 600 / 14px。
  - 激活态（审计）：文字 `ink` #0e0f0c 600；底部指示条 3px 高、宽同文字、圆角 2px，填充 `primary` #9fe870（品牌强调，非成功语义）。
  - 非激活：文字 `body` #454745 400（"Noto Sans SC" 400 / 14px）；hover 文字变 `ink` #0e0f0c。
  - 不再使用现状的蓝色文字 + 蓝色下划线。

## 3 逐区域详细规格

### ① 审计统计卡行（y 184–288）
4 张等宽卡片横向排列，间距 16px（`spacing.lg`），单卡高 104px。

- 卡片结构（对应 `card-content`）：背景 `canvas` #ffffff，圆角 `rounded.xl` 24px，内距 24px，**无边框无阴影**（靠鼠尾草底衬托）。
- 卡内布局：数字在上（"Noto Sans SC" 900 / 40px / 行高 34px），间距 4px，标签在下（"Noto Sans SC" 400 / 14px / 20px）。
- 四张卡内容与样式：
  1. 「600 / 近 30 天变更」：数字 `ink` #0e0f0c，标签 `mute` #868685，白卡。
  2. 「23% / AI 产出占比」：改用 `card-feature-green`——背景 `primary-pale` #e2f6d5，数字 `ink` #0e0f0c 900，标签 `positive-deep` #054d28 400 / 14px。此为品牌强调卡（AI 是产品亮点），绿底不是成功状态。
  3. 「27 / 联动影响次数」：数字 `ink` #0e0f0c，标签 `mute` #868685，白卡。
  4. 「9 / 需求返工次数」：数字 `ink` #0e0f0c，标签 `mute` #868685，白卡（统计数字统一 ink 900，不按语义染色；语义由事件行类型点承担）。
- 废除现状的紫 / 橙 / 红彩色数字。

### ② 分布区行（y 304–536）

**左卡「操作者分布 · 近 30 天」**（宽自适应 ≈1392px）：
- 背景 `canvas` #ffffff，圆角 24px，内距 24px。
- 卡标题：「操作者分布 · 近 30 天」，"Noto Sans SC" 600 / 24px / `ink` #0e0f0c，与首行间距 20px。
- 三条 actor 横条行，行间距 20px，每行结构：标签列（固定宽 200px）→ 轨道条（自适应宽）→ 数值列（右对齐，宽 120px）。
  - 标签列两行：actor 标识 "Noto Sans SC" 600 / 14px / `ink` #0e0f0c（如 "human"），下行中文说明 400 / 12px / `mute` #868685（如 "人类操作"）。
  - 轨道条：高 12px，圆角 pill（9999px），底 `canvas-soft` #e8ebe6；填充段同高同圆角，宽度按占比。
  - 数值列：「312 次 · 52%」，"Noto Sans SC" 600 / 14px / `ink` #0e0f0c。
- 三行填充色（分段色仅作数据可视化区分，不承载状态语义）：
  - human 人类操作（312 次 · 52%）：`ink` #0e0f0c
  - ai:analysis AI 分析（138 次 · 23%）：`primary` #9fe870（Wise 绿 = 品牌强调 AI 产出）
  - mcp:claude-code agent（150 次 · 25%）：`accent-cyan` #38c8ff（规范内三级插画 accent，仅限本图表分段使用，不作 UI 强调色）

**右卡「变更实体类型分布」**（固定宽 464px）：
- 背景 `canvas` #ffffff，圆角 24px，内距 24px。
- 卡标题：「变更实体类型分布」，"Noto Sans SC" 600 / 24px / `ink` #0e0f0c，与首行间距 20px。
- 四个行块，块间距 16px：每块 = 标签行（高 20px）→ 间距 6px → 轨道条（高 8px，圆角 pill，底 `canvas-soft` #e8ebe6，填充段按占比）。
  - 标签行：类型名 "Noto Sans SC" 600 / 14px / `ink` #0e0f0c + 空格 + 百分比 400 / 14px / `mute` #868685，如「需求点 45%」。
- 四块填充色（与左卡分段色系呼应）：
  - 需求点 45%：`ink` #0e0f0c
  - 任务 30%：`primary` #9fe870
  - 素材 15%：`accent-cyan` #38c8ff
  - 分组/项目 10%：`mute` #868685

### ③ 过滤器 pills 行（y 572–608）
5 个 pill 横排：全部 600 / 需求点 270 / 任务 180 / 素材 90 / 分组/项目 60。高 36px，圆角 pill，内距 8px 16px，pill 间距 8px。pill 内：名称与计数并排，间距 6px。

- 激活 pill（全部 600）：背景 `ink` #0e0f0c，名称 "Noto Sans SC" 600 / 14px / `canvas` #ffffff，计数 400 / 14px / `canvas-soft` #e8ebe6。
- 非激活 pill：背景 `canvas` #ffffff（白卡浮于鼠尾草底，无描边），名称 600 / 14px / `ink` #0e0f0c，计数 400 / 14px / `mute` #868685；hover 背景 `canvas-soft` #e8ebe6。
- 刻意不用 `primary` 绿底做激活态——绿严格保留给 CTA 与品牌强调，避免与图表分段绿混淆。

### ④ 变更时间线（y 640 起）
- **标题行**：左「变更时间线」，"Noto Sans SC" 600 / 24px / `ink` #0e0f0c；右 `get_project_audit_report`，"Noto Sans SC" 400 / 12px / `mute` #868685（保留现状的调用名小字）。标题行与列表间距 20px。
- **分组标题**：「今天」「昨天」「更早」，"Noto Sans SC" 600 / 12px / `mute` #868685，高 24px；组标题与组内首行间距 8px，组与上一组末行间距 16px。
- **事件行**（每行高 56px，行间距 8px）：背景 `canvas` #ffffff，圆角 `rounded.xl` 24px，水平内距 24px，内容垂直居中，无边框无阴影。行内从左到右：
  1. 类型点：直径 8px 实心圆，颜色按事件类型（见下）。
  2. 间距 12px。
  3. 类型徽章：pill，背景 `canvas-soft` #e8ebe6，文字 "Noto Sans SC" 600 / 12px / `body` #454745（如 update / linkage_impact / status_change / create / confirm），内距 4px 12px。徽章统一中性化，语义色收敛到类型点。
  4. 间距 12px。
  5. 摘要文字："Noto Sans SC" 400 / 16px / `body` #454745；其中实体名（如「需求点实质修改触发联动」、Task 名称）用 600 / 16px / `ink` #0e0f0c；状态字样（v2→v3、done、draft→confirmed、(draft)、needs_reassessment）保持摘要色不单独染色。
  6. 弹性空隙。
  7. actor 标识："Noto Sans SC" 400 / 14px / `body` #454745（human / ai:analysis / mcp:claude-code 统一灰阶文字——绿、青均不作白底文字色），宽约 110px 右对齐。
  8. 间距 16px。
  9. 时间戳："Noto Sans SC" 400 / 12px / `mute` #868685（如「今天 11:20」「09-10 16:40」），宽约 90px 右对齐。
- **类型点颜色映射**：
  - `create` → `ink` #0e0f0c
  - `update` → `body` #454745
  - `status_change` → `mute` #868685
  - `confirm` → `positive` #2ead4b（确认 = 正向语义，用 positive 族而非 Wise 绿）
  - `linkage_impact` → `warning-deep` #b86700（联动影响 = 警示语义）

## 6 与现状差异要点

1. **底色翻转为鼠尾草**：全白页面 → `canvas-soft` #e8ebe6 页面底 + 白卡 24px 圆角无边框无阴影，靠表面对比分层；顶部 TopBar 与项目上下文条保留白带形成「白 → 鼠尾草」节奏。
2. **统计数字去彩归一**：紫（23%）/ 橙（27）/ 红（9）彩色数字全部改为 `ink` #0e0f0c 900 / 40px 大显示字；「AI 产出占比」卡改为 `primary-pale` #e2f6d5 品牌强调卡承载亮点。
3. **图表分段色换血**：actor 分布与实体分布的绿/紫/蓝/灰随意配色，统一为规范内四色系 `ink` #0e0f0c / `primary` #9fe870 / `accent-cyan` #38c8ff / `mute` #868685，两图同族呼应；分段色仅作可视化区分，不承载状态语义。
4. **导航与过滤器去蓝**：Tab 激活的蓝字蓝下划线 → `ink` 600 文字 + 3px `primary` 品牌绿指示条；过滤器激活的浅蓝底蓝字 pill → `ink` #0e0f0c 深底白字 pill；「active」徽章与状态语义全部换用 positive 族规范 token。
5. **时间线降噪**：彩色类型徽章统一为中性 `canvas-soft` pill，事件语义收敛到 8px 类型点（confirm=`positive`、linkage_impact=`warning-deep`、其余灰阶）；actor 文字去彩色改灰阶 `body`，时间戳统一 `mute` caption。
