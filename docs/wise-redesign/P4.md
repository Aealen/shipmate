# P4 需求点详情 · Wise 重设计规格

> 画板 1920×1080。规范唯一真相源：`wise/DESIGN.md`。字体全局约定：显示层大标题 Noto Sans SC 900；次级标题/导航/Tab/按钮 Noto Sans SC 600；正文 Noto Sans SC 400。信息架构、功能区、文案全部保持现状，只换视觉。
> 本页核心换血：**清除现状蓝/紫/橙彩条编码**（变更历史四色顶条、蓝色操作按钮、蓝色头像全部退场），头部操作组改为「唯一绿 CTA + 白底描边次级」主次分层；needs_reassessment 警示态落到 warning 黄族并配行内绿 CTA「确认重估」；变更历史类型色彩编码收敛进规范 token 体系并与 P2 动态类型四分色同族。
> 现状布局瑕疵修正：截图中头部操作组按钮与右栏「变更历史」标题重叠（见 `.pen-export/wise-input/v5zR3V.png`），本规格将操作组收进点头部行右端，两栏自其下方的 y=320 起，不再重叠。

## 6 与现状差异要点

1. **彩色编码体系退场**：变更历史的黑/蓝/橙/紫四色通栏顶条、蓝色操作按钮、蓝色头像、蓝色链接全部清除；类型与状态编码收敛为规范 token 的 pill 徽章（中性灰 / 浅绿 positive 族 / 中性绿激活填充 / warning 黄族），与 P2 动态类型四分色同族跨页一致。
2. **操作组主次重分层**：现状「绿实心 + 浅蓝描边 + 蓝实心」三颗异质按钮 → 「唯一亮绿 pill 主 CTA（随状态机换文案）+ 两颗白底 ink 描边次级」；同时修正了现状按钮与右栏标题重叠的布局瑕疵。
3. **表面换血**：页面底由灰白改为鼠尾草 `{colors.canvas-soft}` #e8ebe6，全部内容收进白底 24px 圆角卡（溯源卡/任务卡/变更条目卡），靠表面对比做层次、去分割线去阴影。
4. **needs_reassessment 从隐性到显性**：现状警示任务与普通任务几乎无差 → warning 黄族完整警示行（左缘黄竖条 + 待重估 pill）+ 行内绿 CTA「确认重估」，警示语义与修复动作同场呈现。
5. **字体全面 Noto Sans SC 化**：点标题 32px/900、区块标题与徽章按钮 600、正文 400 三档分层；替换现状系统字与"加粗即重"的单一层级。
