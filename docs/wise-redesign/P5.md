## 1 布局骨架

1920×1080 画布，自上而下三个横带，无左侧栏（本页为 TopBar + 项目上下文条 + 全宽四列看板）：

```
┌──────────────────────────────────────────────────────────────────┐
│ TopBar  高 56px · 白底 #ffffff                    （横带 1）      │
├──────────────────────────────────────────────────────────────────┤
│ 项目上下文区（鼠尾草底开始）高约 120px                             │
│   行1  项目名 + active 徽章 ···· 右端「项目概览 ›」  约 44px       │
│   行2  五个 Tab 均分整行                            48px          │
├──────────────────────────────────────────────────────────────────┤
│ 看板区（鼠尾草底延续）剩余高度 ≈ 856px，区域内部滚动               │
│   padding: 24px 32px 32px                                        │
│   四列等宽 grid · 列间距 24px                                     │
│   列宽 = (1920 − 32×2 − 24×3) ÷ 4 = 446px                        │
│   列结构 = 列头 32px + 间距 12px + 卡片垂直栈（卡间距 16px）       │
└──────────────────────────────────────────────────────────────────┘
```

- 横带 1 与横带 2/3 之间无描边，靠 白 #ffffff → canvas-soft #e8ebe6 的表面色差分界（规范 Elevation Level 2：表面对比即层次）。
- 看板四列直接坐在 canvas-soft 上，**列本身不做底色容器**；只有任务卡是白色 card-content。
- 四列均无内容滚动需求时保持自然高度；任一列超长则整区内部滚动，列头随区滚动（与现状一致）。

## 3 逐区域详细规格

### 3.1 看板列（×4）

- 列宽 446px，列间距 24px；列背景透明（即页面底 canvas-soft #e8ebe6）。
- 列头（高 32px，下距 12px），从左到右：
  1. 状态色点：直径 10px 圆形，实心。四列色见 §5。
  2. 色点右 8px：列名 14px fontWeight 600 · ink #0e0f0c。第四列列名「待重估」，需求已变更时后缀「（需求已变更）」，后缀部分 14px fontWeight 400 · warning-deep #b86700。
  3. 列名右 8px：计数徽章——白底 canvas #ffffff pill，字 12px fontWeight 600 · ink #0e0f0c，padding 2px 10px，圆角 9999px，数字居中（如 3 / 2 / 4 / 3）。

### 3.2 任务卡（通用，card-content）

- 表面：canvas #ffffff；**无边框、无阴影**（表面对比即层次）。
- 形状：rounded.xl = **24px 圆角**；内距 16px 20px；卡与卡垂直间距 16px。
- 结构（两行）：
  - 行1：左 · 任务标题，16px fontWeight 600 · ink #0e0f0c（如「confirm_task_reassessment 工具」）；右 · actor 徽章（见 §3.4），垂直居中对齐行1。
  - 行2（上距 6px）：来源行，12px fontWeight 400 · mute #868685（caption），文案保持现状：「联动规则 · v1」「MCP 工具面」「需求分析 · v2」等。
- 卡片约 78px 高；hover 时表面不变、无位移（Wise 克制风格），仅 cursor: grab。

### 3.3 重估卡（needs_reassessment 列专用，任务卡变体）

在 §3.2 基础上增加：

- **警示顶条**：卡片最顶部一条 **6px 高、全宽、warning #ffd11a** 实色条；卡片 overflow:hidden 使顶条随 24px 圆角裁切（替换现状橙色条）。
- 行2 来源行下 12px：全宽操作按钮「确认重估 · 回到待办」→ **button-primary**：
  - 底 primary #9fe870，字 on-primary #0e0f0c；16px fontWeight 600（button-md）；高 48px，宽 100%，圆角 24px；按下态底 primary-active #cdffad。
  - 唯一使用亮绿的元素即此 CTA 与 Tab 指示条，全页不得再有第三处。

### 3.4 actor 徽章（三类可区分，全部规范内表面 + 前缀图标区分）

徽章统一：高 24px，padding 4px 10px，pill 圆角 9999px，字 12px fontWeight 600。

| actor | 表面 | 文字 | 前缀图标 |
|---|---|---|---|
| human | canvas-soft #e8ebe6 实底 | ink #0e0f0c | 12px 人形线性图标，色 ink #0e0f0c |
| ai:analysis | primary-pale #e2f6d5（badge-positive 原样表面） | positive-deep #054d28 | 12px ✦ 星火图标，色 positive-deep #054d28 |
| mcp:claude-code | canvas #ffffff + 1px ink #0e0f0c 描边 | ink #0e0f0c | 12px `>_` 终端图标，色 ink #0e0f0c |

- 区分通道以**前缀图标为主、表面为辅**；白卡上三类分别为「灰实底 / 淡绿底 / 白底描边」，扫视可辨。
- ai:analysis 的淡绿底仅为 badge-positive 组件表面复用（规范原生徽章底），**不是**成功状态语义；严禁改用 positive #2ead4b 实色或引入蓝/紫（现状蓝紫徽章废除）。

### 3.5 空列占位

- 列无卡时显示一张占位卡：canvas #ffffff，24px 圆角，padding 48px 24px（ex-empty-state-card 形态），居中一行 14px fontWeight 400 · mute #868685：「暂无任务，可拖动任务到此列」（现状文案）。

## 5 状态与语义色

| 状态 | 语义 | 色点/色值 | 徽章/呈现 |
|---|---|---|---|
| pending 待办 | 未开始·中性 | mute #868685 | 无徽章，仅列头色点 |
| in_progress 进行中 | 活跃·品牌强调 | primary #9fe870 | 无徽章，仅列头色点；亮绿在此表示「进行中」的品牌强调，**非成功语义** |
| done 已完成 | 成功 | positive #2ead4b | 无徽章，仅列头色点（成功语义用 positive 族，不用品牌亮绿） |
| needs_reassessment 待重估 | 警示 | warning #ffd11a | 列头色点 + 卡片 6px 顶条；列名后缀「（需求已变更）」用 warning-deep #b86700；顶条上的正文如需警示文字用 warning-content #4a3b1c |
| 项目 active | 正面状态 | — | badge-positive（primary-pale #e2f6d5 底 + positive-deep #054d28 字） |
| actor human / ai:analysis / mcp:claude-code | 执行者标识（非状态） | — | §3.4 三表面徽章；禁止用 positive/warning/negative 实色表达 actor |
| 超期任务（若卡上出现「已超期 {days} 天」） | 危险 | negative #d03238 | 12px fontWeight 600 字色 negative-deep #a72027，不加底色 |
| 分析失败（若流出到看板） | 危险 | — | badge-negative 形态：底 negative-bg #320707，字 #ffffff，pill |

红线自查：全页唯一绿色系状态色是 done 的 positive #2ead4b（成功正当用法）；primary #9fe870 仅出现在 CTA 按钮与 Tab 指示条、in_progress 色点（品牌强调）；无蓝、紫、青等第二强调色。

## 6 与现状差异要点

1. **页面底换血**：白 TopBar + 浅灰看板区 → TopBar 保持白（nav-bar），其余整页换成鼠尾草 canvas-soft #e8ebe6；任务卡白底 24px 圆角、去尽边框阴影，纯靠表面对比分层。
2. **蓝色清零**：Tabs 激活蓝色下划线 → ink 600 字 + primary #9fe870 绿色短指示条；重估列蓝色按钮 → button-primary 亮绿 #9fe870 黑字 24px 圆角；「开发中」蓝点 → 现行文案「进行中」+ primary 色点。
3. **actor 三彩徽章降维**：现状绿/蓝/紫三彩底 → 规范内三表面（sage 实底 / primary-pale / 白底描边）+ 前缀图标区分，消灭第二强调色。
4. **警示语义归位**：重估卡橙色顶条 → warning #ffd11a 标准警示族（顶条 + 后缀文字 warning-deep #b86700）；已完成语义从绿点泛用 → 正式落到 positive #2ead4b。
5. **字体层级重排**：现状杂混字重 → 项目名「ShipMate」Noto Sans SC 900 / Tab·按钮·卡标题·列名 600 / 正文与来源行 400，字色只允许 ink/body/mute 三档。
