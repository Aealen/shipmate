# P1 项目列表首页 · Wise 重设计规格

> 依据 `wise/DESIGN.md`（唯一真相源）。信息架构、功能区、文案保持现状不变，仅换视觉设计语言。
> 中文字体全局约定：显示层大标题 Noto Sans SC 900；次级标题/导航/Tab/按钮 Noto Sans SC 600；正文 Noto Sans SC 400。
> 画板 1920×1080，桌面 Web App。

## 1 布局骨架

1920×1080 三段式骨架（自上而下、自左而右）：

```
┌──────────────────────────────────────────────────────────────┐
│ TopBar 全宽 h=64px，canvas #ffffff                           │
│  [logo 区 240px 宽]              …空…            [头像 36px] │
├──────────────┬───────────────────────────────────────────────┤
│ 侧栏 w=240px │ 内容区 w=1680px，canvas-soft #e8ebe6          │
│ canvas 白    │  padding: 48px 48px 48px 48px                 │
│ h=1016px     │  ┌ 标题行 h=48px ────────────── [+ 新建项目]┐ │
│              │  ├ 间距 32px ──────────────────────────────┤ │
│              │  ├ 项目卡片网格 2 列 × 3 行                 │ │
│              │  │  卡片 w=780px h≈204px                    │ │
│              │  │  列间距 24px，行间距 24px                 │ │
│              │  └──────────────────────────────────────────┘ │
└──────────────┴───────────────────────────────────────────────┘
```

- **TopBar**：x=0，y=0，w=1920，h=64px。
- **侧栏**：x=0，y=64，w=240，h=1016（到画板底）。
- **内容区**：x=240，y=64，w=1680，h=1016。
- **标题行**：内容区顶部，y=64+48=112，高 48px（标题文字行高）；右端 CTA 高 48px 与之垂直居中对齐。
- **卡片网格**：标题行下 32px（spacing.2xl）起；可用宽 1680−96=1584，2 列 → 卡宽 (1584−24)/2 = **780px**，卡高约 **204px**（内容自适应，最小 204）。3 行卡片总高 3×204+2×24=660px，y≈192~852，底部余白充足。

## 2 全局元素规格

### TopBar（对应 `nav-bar`）
- 背景 `canvas` #ffffff，无边框无阴影；与下方内容区靠白 vs 鼠尾草的**表面对比**分隔（不加分隔线）。
- 内距：水平 24px（spacing.xl），垂直居中。
- **Logo（左侧，落在 240px 侧栏区内）**：锚形图标 24×24px，填充 `primary` #9fe870（品牌强调位，允许用绿）+ 品牌字 "ShipMate"，fontFamily "Noto Sans SC" fontWeight **900**，20px，`ink` #0e0f0c，与图标间距 8px。
- **头像（右侧）**：直径 36px 圆形（rounded.full），背景 `ink` #0e0f0c，内文字 "明" 14px / "Noto Sans SC" **600**，色 `canvas` #ffffff。头像外无边框。hover：外圈 2px `primary` #9fe870 描边。

### 侧栏（对应 `ex-app-shell-row` 行 + `nav-link` 字级）
- 背景 `canvas` #ffffff，无边框；内距：左右 16px（spacing.lg），顶部 16px。
- **"分组" 小标题**：12px / "Noto Sans SC" 400，`mute` #868685，行高 32px，左内距 12px。
- **导航行（全部项目 / 华信·智慧投标 / Maxon 实验室 / 未分组）**：
  - 行高 40px，宽 240−32=208px，内距左右 12px，行间距 4px，圆角 `rounded.sm` 8px。
  - 文字：14px / "Noto Sans SC" **600**，色 `ink` #0e0f0c。
  - 右端计数徽章：12px / 600，默认 `mute` #868685。
  - **默认态**：透明背景（白）。
  - **激活态（"全部项目"）**：背景 `canvas-soft` #e8ebe6，圆角 8px；行左缘竖指示条 4px 宽 × 16px 高、圆角 pill、色 `primary` #9fe870（规范 `ex-app-shell-row` 的 brand-primary 指示器）；计数徽章变 `ink` #0e0f0c。
  - hover（非激活行）：背景 `canvas-soft` #e8ebe6，无指示条。
- **"+ 新建分组"（次级动作入口，非导航）**：行高 40px，"+" 图标 16px `body` #454745 + 文字 14px / "Noto Sans SC" 400，色 `body` #454745；hover 文字与图标变 `ink` #0e0f0c。与上方导航组间距 8px。

## 3 逐区域详细规格

### 3.1 标题行（y≈112，h=48px）
- 结构：横向 flex，三元素——页面标题、meta 说明、右侧 CTA，垂直居中。
- **页面标题 "全部项目"**：显示层大标题 → "Noto Sans SC" **900**，40px，行高 48px，色 `ink` #0e0f0c。
- **meta "6 个项目 · 3 个分组"**：14px / "Noto Sans SC" 400，色 `mute` #868685，紧随标题右侧、间距 16px，基线对齐。
- **CTA "+ 新建项目"**：`button-primary` → 背景 `primary` #9fe870，文字 `on-primary` #0e0f0c，"Noto Sans SC" **600** 16px，padding 12px 24px（spacing.md / spacing.xl），圆角 `rounded.xl` **24px**，高 48px。"+" 图标 16px 同色。hover：背景 `primary-active` #cdffad；active：背景 `primary-neutral` #c5edab。**此按钮是全页唯一的绿色大色块。**

### 3.2 项目卡片（`card-content`，2 列 × 3 行）
- 背景 `canvas` #ffffff，**无边框、无阴影**，圆角 `rounded.xl` **24px**，内距 24px（spacing.xl）。整体可点击进入项目。
- hover：出现轻阴影 `0 4px 16px rgba(14,15,12,0.08)`，transition 150ms；光标 pointer。不做边框变化。
- 内部纵向结构（自上而下）：

| 行 | 内容 | 规格 |

| ① 项目名行 | 项目名 + 右侧分组徽章，两端对齐 | 项目名："Noto Sans SC" **600** 20px，行高 28px，`ink` #0e0f0c。徽章见 §3.3 |
| ② 间距 8px | — | spacing.sm |
| ③ 描述 | 一行说明文案 | 14px / "Noto Sans SC" 400，行高 20px，色 `body` #454745 |
| ④ 间距 16px | — | spacing.lg |
| ⑤ 进度行 | 进度条 + 右侧完成度说明，垂直居中，高 20px | 进度条：高 **8px**、圆角 `rounded.pill`，轨道 `canvas-soft` #e8ebe6、填充 `ink` #0e0f0c，宽度撑满剩余空间。右侧文字："52%"（14px / 600 / `ink` #0e0f0c）+ " 需求点完成"（12px / 400 / `mute` #868685），与进度条间距 12px |

## 5 状态与语义色

统计行四状态 + 备用业务状态的 Wise 语义映射（**Wise 绿 #9fe870 绝不表示任何状态**）：

| 业务状态 | 圆点（8px） | 文字/数字 | 徽章形态（如需） |
|---|---|---|---|
| done 已完成 | `positive` #2ead4b | 名称 12px 400 `body` #454745；数量 12px 600 `ink` #0e0f0c | `badge-positive`：bg `primary-pale` #e2f6d5 + 字 `positive-deep` #054d28，pill，padding 4/12（此为规范定义的 positive 语义徽章，非品牌强调） |
| developing 开发中 | `ink` #0e0f0c（进行中用中性深色，**不用蓝/青**，避免第二强调色） | 同上 | 中性 pill：bg `canvas-soft` #e8ebe6 + 字 `body` #454745 |
| draft 草稿 | `mute` #868685 | 同上 | 中性 pill：同上 |
| needs_reassessment 待重估 | `warning` #ffd11a | 强调时文字可用 `warning-content` #4a3b1c | bg `warning` #ffd11a + 字 `warning-content` #4a3b1c，pill，padding 4/12 |
| 超期（本页暂无，备用） | `negative` #d03238 | `negative-darkest` #a7000d | `badge-negative`：bg `negative-bg` #320707 + 白字 #ffffff，pill |
| 分析失败（本页暂无，备用） | `negative` #d03238 | `negative-darkest` #a7000d | 同 `badge-negative` |

- 进度条填充为 `ink` #0e0f0c，属数据可视化中性色，**不是**成功语义，不占用绿色。
- 全页绿色仅出现在：① "新建项目" CTA；② 侧栏激活指示条；③ Logo 图标。三处均为 CTA / 品牌强调，符合红线。

## 6 与现状差异要点

1. **底色体系换血**：内容区从均质浅灰 #f6f7f9 换成鼠尾草 `canvas-soft` #e8ebe6，白卡 #ffffff 24px 圆角浮于其上——层次全靠表面对比，卡片去边框去阴影。
2. **品牌色全灭换唯一绿**：现状的蓝色（新建项目按钮、进度条、进入项目链接、侧栏激活底、头像）全部清除；亮绿 `primary` #9fe870 只保留在"新建项目"CTA、侧栏激活指示条、Logo 三处，全页无第二强调色。
3. **圆角语言升级**：按钮/卡片从 8px 小圆角改 24px `rounded.xl`，徽章改全圆 pill，头像保持正圆——Wise 的"友好胶囊"几何。
4. **状态色重映射**：已完成绿点改 `positive` #2ead4b 语义绿（不再与品牌绿混淆），开发中蓝点改 `ink` 中性黑点，待重估橙点改 `warning` #ffd11a，进度条蓝条改 `ink` 近黑——品牌绿与状态色彻底分离。
5. **字体三档化**：系统字替换为 "Noto Sans SC"——页面标题 900、项目名/导航/按钮/徽章 600、描述与辅助文字 400，形成 Wise 式"重标题 + 中性正文"对比。
