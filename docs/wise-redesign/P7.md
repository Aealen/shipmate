## 6 与现状差异要点

1. **页面底换血**：现状整页近白底 → 鼠尾草 `{colors.canvas-soft}` `#e8ebe6` 页面底 + 纯白 24px 圆角卡片，去掉卡片细边框/阴影，靠表面对比分层。
2. **去蓝色第二强调色**：现状蓝色"推荐"徽章与蓝色头像全部移除——推荐徽章改 Wise 绿 pale 品牌强调（#e2f6d5/#163300），头像改 `{colors.ink}` 深色圆；全页不再出现蓝色。
3. **复制动作 Wise 化 + 成功态规范化**：两处复制按钮统一为 24px 圆角 button-secondary（URL 框内 12px 缩小版）；点击后文案切"已复制"+对勾，配色用 positive-deep #054d28（成功语义），而非借用品牌亮绿。
4. **代码块降调**：现状深蓝黑代码块 → `{colors.ink}` `#0e0f0c` 深块 + 16px 圆角，代码文字只用白/鼠尾草灰阶层次，去掉现状的彩色语法高亮，杜绝第二强调色。
5. **字重体系重排**：页标题"MCP 接入"改 Noto Sans SC 900（28px），卡标题/按钮/徽章组名 600，说明与计数 400，TopBar 面包屑当前页 600——替换现状均质粗细。
