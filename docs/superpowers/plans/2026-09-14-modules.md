# ShipMate 模块(Module)实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地 项目 → 模块 → 需求 三级结构(spec D8/D9):core modules 表与服务、需求挂载模块、MCP 4 工具、AI 逐块归类建议、P3 模块分组 UI、工作台归类行、看板/进度模块筛选。

**Architecture:** modules 新表(纯分类容器,无状态无排期);requirements 加可空 `module_id`;AI 分析草稿块带 `module` 建议字段,apply 时按名匹配已有模块否则新建;web 全链路按模块分组与筛选。

**Tech Stack:** PostgreSQL + drizzle-orm(node-postgres)/ TypeScript strict ESM(nodenext,相对导入带 .js)/ Next.js 15.5 + Tailwind v4 语义 tokens / next-intl(zh-CN/en 键对称)/ vitest(真实库事务回滚)。

**Spec:** `docs/design.md`(§3.9 modules、§3.4 requirements.module_id、§6 ModuleService、§8 模块工具组、§9 规则 10、§13 D8/D9、§14 模块分组与筛选)。原型:`shipmate.pen` P3k(x=26000,模块分组列表)/ P3l(x=28000,工作台归类行)。

## Global Constraints

- core 禁止 import next / mcp sdk;web、mcp 只经 core 门面,禁止反向依赖
- 所有时间戳 bigint 毫秒;主键 UUID v7 text(`newId()`);枚举列 text + drizzle enum 参数
- 所有写操作带 actor 并写 change_logs;模块 entity_type = `module`
- 相对导入必须带 `.js` 后缀;测试断言一律按新建实体 id 过滤(库里有「演示-」前缀历史数据,禁止全表 count 断言)
- i18n:zh-CN.json 与 en.json 键对称;改 messages 用 Edit 精确锚点插入,禁整文件重写
- UI 颜色只用语义 tokens(bg-surface/surface-2/bg/border/accent/accent-dim/text-*/danger/warning/success/ai)
- git commit 由主会话收口统一执行,subagent 不做 git 操作
- 服务启动:`pnpm -C packages/web build && pnpm -C packages/web start`(端口 47610);并行验证用 47611 等换端口
